# Метро · запись

Приложение для Android, которое во время поездки в метро записывает всё, что видит телефон.
Это первый шаг к приложению-подсказчику станций: по этим записям мы поймём, где стоят
точки AI-THINKER, как ведут себя Wi-Fi вагонов, вышки, GPS и датчики.

## Что записывается

| Файл | Что внутри |
|---|---|
| `wifi.csv` | Каждая увиденная Wi-Fi сеть: название, уникальный номер точки (BSSID), сила сигнала, частота |
| `wifi_scans.csv` | Каждый поиск Wi-Fi: разрешил ли Android, сколько сетей нашлось |
| `cells.csv` | Вышки сотовой связи: тип (LTE/5G/…), оператор, номер зоны и вышки, сигнал |
| `locations.csv` | Координаты от GPS и от сети |
| `gnss.csv`, `gnss_raw.csv` | Спутники и сила их сигнала (помогает заметить подмену GPS) |
| `sensors.csv` | Датчики: A — ускорение, G — повороты, M — магнитное поле, R — положение телефона, P — давление (барометр), L — свет, S — шаг |
| `battery.csv` | Заряд и ток батареи раз в 30 секунд |
| `marks.csv` | Ваши отметки кнопками |
| `events.csv` | Служебные события: экран вкл/выкл, ошибки и т. п. |
| `meta.json` | Модель телефона, список датчиков, время начала и конца |

Время во всех файлах — `t_ms`, миллисекунды с момента включения телефона. Перевод в обычное
время описан в `meta.json`.

## Установка

1. Откройте вкладку **Actions** этого репозитория → последний успешный запуск
   «Metro Recorder APK» → внизу раздел **Artifacts** → скачайте `MetroRecorder-N`.
2. Внутри архива — файл `.apk`. Откройте его на телефоне и разрешите установку
   из этого источника.
3. Новые версии ставятся поверх старой, записи не теряются.

## Подготовка телефона (один раз)

В приложении есть блок «Подготовка телефона»:

1. **Разрешения** — геопозиция (точная), уведомления, устройства поблизости, физическая активность.
   Без точной геопозиции Android не показывает приложению Wi-Fi сети и вышки.
2. **Батарея** — снять ограничения, чтобы запись не засыпала при выключенном экране.
3. **Ограничение поиска Wi-Fi** — по умолчанию Android разрешает искать сети 4 раза за 2 минуты.
   Выключите его: Настройки → Сведения о телефоне → Сведения о ПО → 7 раз нажать «Номер сборки»;
   затем Настройки → Параметры разработчика → пункт про ограничение поиска Wi-Fi
   (Wi-Fi scan throttling) → выключить.
4. Wi-Fi и геолокация должны быть включены (подключаться к сети не нужно).

## Как записывать поездку

1. На улице, перед входом в метро: выберите ветку и станцию, нажмите «Начать запись».
2. Отмечайте события: «Вход в метро» → «На платформе» → «Сел в вагон».
3. В вагоне: «Тронулись» при отправлении, «Тормозим» — как только почувствовали торможение
   перед станцией, «Прибыли» — когда поезд встал (станция подставится сама).
   «Двери слева/справа» — с какой стороны открылись двери по ходу движения.
   Три главные кнопки есть и в уведомлении на экране блокировки.
4. Пересадка: выберите новую ветку и станцию.
5. На выходе: «Вышел из вагона» → «На улице» → «Остановить».

Архив поездки появится в «Загрузки/MetroRecorder» и в списке «Записи» в приложении.
Отправить его можно кнопкой «Отправить».

## Важно

- Репозиторий публичный. **Не загружайте сюда записи** — в них ваша геопозиция.
- Ключ подписи `app/debug.keystore` — тестовый, он лежит в репозитории, чтобы каждая сборка
  ставилась поверх предыдущей. Для приложения «для себя» это нормально; для публикации нужен
  свой закрытый ключ.

## Сборка

Собирается автоматически в GitHub Actions при каждом изменении папки `metro-recorder`.
Локально: `./gradlew assembleRelease` (нужен Android SDK).
